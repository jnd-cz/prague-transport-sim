# Asset register

Every file in the repository that is not code written for this project, with its source and licence.
Nothing third-party goes into the repository without an entry here, and only under a licence that
allows redistribution (CC0, CC BY, CC BY-SA, CC BY-NC, …). The code is AGPL-3.0 ([LICENSE](LICENSE), #518);
the project's own assets are listed with their own licence. Adding a vehicle model: [docs/vehicles.md](docs/vehicles.md);
each vehicle's `assets/<id>/vehicle.json` repeats its licence, authors and credit for the game, and
`tools/test_vehicles.py` checks its files have a row here.

Generated in code, part of the AGPL-3.0 code: the built-in tram (`src/t3simple.js`: its shapes measured
on a general-arrangement drawing and a colour elevation of the T3, which are not copied into the repository,
#427), cars, people, signals, signs and street furniture (`src/models.js`), textures drawn on canvas
(the tram's livery, plates, facades, signs), and all sound
(built-in Web Audio synthesis, `src/audio.js`; the optional sample pack above uses the same licence). Models made for the project by agents are AGPL-3.0 as well
([decision](docs/decisions/2026-10-29-tests-and-licences.md)), each with an entry here.

Further assets from the T3 and street furniture labs are listed with
their licences in [docs/assets-inventory.md](docs/assets-inventory.md).

Not in the repository: the world data built from public sources (see [NOTICE.md](NOTICE.md)) and the
raw sources themselves, both in the data store ([DATA.md](DATA.md)).

**OSM2World** (planned study, #15): its code is MIT; any code ported from it keeps its copyright notice
here and in the file. Its bundled models and textures carry their own licences and get an entry each
before use.
