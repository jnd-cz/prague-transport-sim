# Data sources and attribution

The game world is built from open data. The built data is not in this repository (it is fetched from
the data store, [DATA.md](DATA.md)); the game shows the attribution line on screen.

| Source | Used for | Licence and credit |
|---|---|---|
| OpenStreetMap (Geofabrik extract) | tracks, roads, stops, signals, buildings (fallback), greenery, water | © OpenStreetMap contributors, [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/) |
| PID GTFS (data.pid.cz) | timetable, stops, lines | ROPID, CC BY 4.0 |
| ČÚZK DMR 5G | terrain | © ČÚZK, CC BY 4.0 |
| ČÚZK correction grid (via PROJ-data) | ETRS89 → S-JTSK conversion | © ČÚZK, CC BY 4.0 |
| IPR Praha Geoportál: Budovy 3D, Mosty 3D, retaining walls, trees, orthophoto | buildings, bridges, walls, trees, lane checks | datový podklad © IPR Praha, CC BY 4.0 |
| Prague Digital Technical Map (DTM, ZPS; archived DTMP) | surveyed streets, kerbs, street furniture | datový podklad © IPR Praha / DTM Praha, CC BY 4.0 |

**ODbL:** the built world data contains data derived from OpenStreetMap. Whoever receives it
(the published game data) receives it under the ODbL: it may be used, shared and adapted, with the
attribution above, and adapted databases shared further must stay under the ODbL.
